# Python to C-family Transpiler (Planning)

Python のソースコードを解析し，変数や関数などの型情報を推論するためのプロジェクトです．まず Python の型解析と中間表現の生成に取り組み，その結果をもとに，将来的には C，C++，C# などの言語へのコード変換を目指します．

> **開発状況:** 現在は Python ソースファイル 1 件を静的解析し，型付き中間表現（`.tir`）と YAML（`.yaml`）を出力する試作段階です．C/C++/C# への変換機能はまだありません．

## 主な機能

- Python の `ast` モジュールを使った静的解析（解析対象のコードは実行しません）
- 変数の代入・型注釈からの型情報の収集
- 関数，引数，戻り値，クラス，メソッド，クラス属性の解析
- リテラル，基本的なコンテナ，呼び出し式の型推論
- 同じ変数に異なる型が代入された場合の Union 型による表現
- 推論が難しい型を `Unknown` として表現
- 人が読みやすい `.tir` と，機械処理向けの `.yaml` の生成

## 必要環境

- Python 3.10 以上
- PyYAML

## セットアップ

```bash
python -m pip install -r requirements.txt
```

## 使い方

### コマンドライン

```bash
python main.py <解析するPythonファイル.py> <出力先ディレクトリ>
```

たとえば，同梱のサンプルを解析する場合:

```bash
python main.py sample.py output
```

または，ランチャーから実行できます．

```bash
python execute.py sample.py output
```

どちらのコマンドでも，指定した出力先に `sample.tir` と `sample.yaml` が生成されます．

### ファイル選択ダイアログ

引数を指定せずにランチャーを実行すると，入力ファイルと出力先を選ぶダイアログが開きます．

```bash
python execute.py
```

GUI の利用には Tkinter が必要です．Python のインストール環境によっては，別途 Tkinter の導入が必要な場合があります．

## 出力形式

- **`.tir`** — 型情報を含む，人が読みやすい中間表現です．
- **`.yaml`** — 同じ解析結果を構造化して保存した YAML 形式です．後続の変換処理で利用することを想定しています．

## ディレクトリ構成

```text
.
├── execute.py       # CLI / ファイル選択ダイアログ用ランチャー
├── main.py          # Python 解析，型推論，中間表現と YAML の生成
├── requirements.txt # Python の依存パッケージ
├── sample.py        # 解析用サンプルコード
└── sample/          # サンプルの解析結果
    ├── sample.tir
    └── sample.yaml
```

## 現在の制約

このプロジェクトは静的解析の試作です．解析結果は実行時の振る舞いを保証するものではなく，動的な型の変化や実行時にしか分からない情報をすべて推論できるわけではありません．現時点では，入力ファイル 1 件ずつを解析します．
